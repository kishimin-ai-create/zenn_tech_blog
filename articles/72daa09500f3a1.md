## なぜ調べたか

PlaywrightでAPIをモックできることを知り、どのように実装するのか気になったため。

## 学んだこと

`page.route()`で対象のAPIを指定し、`route.fulfill()`でモックするレスポンスを設定できる。

## コード例

商品一覧APIをモックし、商品名が画面に表示されることを確認するテストの例。

```ts
test("モックした商品が表示される", async ({ page }) => {
  await page.route("**/api/products", (route) =>
    route.fulfill({
      status: 200,
      body: JSON.stringify([{ id: 1, name: "りんご" }]),
    }),
  );

  await page.goto("/products");

  await expect(page.getByText("りんご")).toBeVisible();
});
```

※ 商品一覧APIと画面を想定した説明用のサンプルコードです。

## 注意

テストを実行するには、Webサーバーを起動する必要がある。

`playwright.config.ts` の `webServer` を設定すると、テスト実行時にWebサーバーを自動で起動できる。これにより、毎回手動で開発サーバーを起動する必要がなくなる。

```ts
webServer: {
  command: "npm run dev -- --host localhost",
  url: "http://localhost:5173",
  reuseExistingServer: !process.env.CI,
},
```

`reuseExistingServer` を設定することで、ローカルですでにWebサーバーが起動している場合は、そのサーバーを再利用できる。

## 一言でまとめると

Playwrightの`page.route()`と`route.fulfill()`を使えば、APIのレスポンスをモックできる。
