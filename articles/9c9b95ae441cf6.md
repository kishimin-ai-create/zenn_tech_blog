対象バージョン

- Tailwind CSS：v4系
- Storybook：v10

## なぜ調べたか

WebアプリケーションのデザインにTailwind CSSを使用するため、基本的な使い方を調べました。

## 学んだこと

### セットアップ

`index.css` にTailwind CSSを読み込みます。

```css
@import "tailwindcss";
```

`main.tsx` から `index.css` を読み込みます。

```tsx
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import App from "./app/pages/App.tsx";
import "./index.css";

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <App />
  </StrictMode>,
);
```

### 基本的なクラス

Tailwind CSSでは、クラスを指定してレイアウトや余白、色などを設定できます。

#### レイアウト

`flex` を指定すると、`display: flex` が適用されます。

#### スペーシング

`p-*` で、`padding`を指定できます。

#### 色

背景色には、次のように任意のカラーコードを指定できます。

```html
<div class="bg-[#50d71e]"></div>
```

#### サイズ

`w-1/2` を指定すると、幅が50%になります。

#### レスポンシブ対応

画面幅に応じてスタイルを切り替えるためのブレークポイントが用意されています。

| プレフィックス | 適用される画面幅 |
| -------------- | ---------------- |
| `sm`           | 640px以上        |
| `md`           | 768px以上        |
| `lg`           | 1024px以上       |
| `xl`           | 1280px以上       |
| `2xl`          | 1536px以上       |

#### 位置

`text-center` を指定すると、`text-align: center` が適用されます。

### Storybookへの適用

StorybookでもTailwind CSSを適用するため、`preview.tsx` から `index.css` を読み込みます。

```tsx
/// <reference types="vite/client" />

import "../src/index.css";
```

## 一言でまとめると

Tailwind CSSでは、クラスを指定することで、レイアウト、余白、色、サイズ、レスポンシブ対応などのスタイルを設定できます。

また、StorybookでもCSSファイルを読み込むことで、Tailwind CSSを適用できます。
