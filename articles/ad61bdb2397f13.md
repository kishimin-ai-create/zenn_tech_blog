## なぜ調べたか

Playwright MCPとCodexを使って、アドホックテストを行ってみたかったため。

## 学んだこと

### Playwright MCPとは

Playwright MCPは、AIエージェントがブラウザを操作するためのMCPサーバーです。

ページのアクセシビリティ情報を利用して、画面遷移やクリック、フォームへの入力などを行えます。

今回はCodexと組み合わせて、アドホックテストを実施しました。

### Playwright MCPの導入方法

CodexでPlaywright MCPを利用できるようにします。

前提として、Node.jsとCodexが必要です。

以下のコマンドを実行します。

```bash
codex mcp add playwright npx "@playwright/mcp@latest"
```

実行すると、Codexの設定ファイル `~/.codex/config.toml` に以下の設定が追加されます。

```toml
[mcp_servers.playwright]
command = "npx"
args = ["@playwright/mcp@latest"]
```

以下のコマンドで、MCPサーバーが登録されているか確認できます。

```bash
codex mcp list
```

## Codexへの指示

今回はCodexに以下のプロンプトを渡して、アドホックテストを実施しました。

```text
アドホックテストをお願いします。
使用可能なログイン情報は、
ユーザー名が、""
パスワードが、""
です。
最後に、実装の証跡としてのスクリーンショットも取得お願いします。

行ったテストはどのような観点で見つけたのか報告お願いします。
自分が書いたテストコードは絶対に参考にしないで下さい。
```

既存のテストコードを参考にせず、Codexにテスト内容を考えてもらうよう依頼しました。

## 実施結果

### テスト結果

Codexにアドホックテストを依頼したところ、ログインや画面遷移、入力操作など、複数の機能に対するテストが実施されました。

その結果、一部の操作で追加確認が必要な点が見つかりました。また、テスト終了後には、実施内容の報告とスクリーンショットを取得できました。

## まとめ

Playwright MCPとCodexを組み合わせて、アドホックテストを実施しました。

既存のテストコードを参考にせず、Codexにテストを任せることで、複数の機能を確認し、追加確認が必要な点も見つかりました。
